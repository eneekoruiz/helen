# Design Direction & Visual System

## 1. Aesthetic Point of View
- **Tone**: Professional, minimalist, modern, highly refined.
- **Reference Inspiration**: Hand-crafted layouts with clear focal points, avoiding generic AI templates.

## 2. Typographic Hierarchy
- **Display / Headings**: Bold, intentional, distinctive serif or crisp grotesque geometric sans.
- **Body Text**: Highly legible neutral sans with 1.5 - 1.6 line height.
- **Monospace / Code**: Clean monospace with tabular figures.

## 3. Color Palette & Dark Mode
- **Backgrounds**: Slate / Deep Obsidian / Pure Clean White.
- **Surface & Cards**: Subtle border highlights, 1px borders with 5% alpha.
- **Accent**: Deliberate single primary accent color used for intentional focus.
- **Contrast**: WCAG AAA standard on all text elements.

## 4. Layout & Spacing System
- Strict 8pt grid system (8px, 16px, 24px, 32px, 48px, 64px, 96px).
- Generous breathing room and asymmetrical whitespace balance.
