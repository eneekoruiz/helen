# Vocabulary and resources (reference, not a mandate)

Concepts and tools referenced by the HELEN 03-finish-features prompts. Use only what the project needs and can afford in performance and accessibility.

- Advanced cursor effects and menu effects (micro-interactions).
- Icon sets and animation tools: Iconsax, Anime.js, SVGator, Jitter.
- Image sequence scrubbing (scroll linked to an image sequence).
- 3D scrolling, 3D video scenes, infinite carousels.
- Unified component libraries that bundle these effects (for example Aceternity UI, Magic UI).
- Native View Transitions API for page and state transitions.
- WebGPU / shader experiences, Spline vs React Three Fiber for 3D.

Search for maintained libraries before writing effects from scratch, and check license, bundle size, and reduced-motion support.
