### Changes applied
- `docs/prompts/STANDARDS.md`: added an Agentic Excellence Protocol covering evidence-first execution, bounded reflection loops, persistent memory, exception handling, and output discipline. Removed a duplicate `GENERATE` section.
- `docs/prompts/PREMIUM_PROMPT_CONTRACT.md`: expanded mandatory quality requirements with evidence, bounded reflection, memory, exception handling, and richer metadata fields.
- `docs/prompts/TAXONOMY.md`: removed duplicate legacy prefix definitions and added an Agentic Quality Gate.
- `docs/prompts/08-maintenance/meta/APPLY-prompt-library-maintenance-flow.md`: upgraded the maintenance flow into an explicit investigate/audit/apply/re-audit/register loop with stop conditions and log requirements.

### Rationale
The repository already had many strong atomic prompts, but the weakest leverage point was inconsistent global enforcement of agentic behavior. Updating shared contracts improves future prompts without risky mass rewrites. The bounded loop preserves the user's recursive-improvement intent while preventing unbounded churn, unverifiable perfection claims, and broad speculative edits.

### Residual risk
- Many existing atomic prompts still lack frontmatter and explicit memory/exception sections. This pass establishes the standard and maintenance mechanism; a later migration can update individual prompts in batches with CLI-aware tests.
- Some prompt files contain decorative separators using `---` outside YAML frontmatter; future tooling should distinguish Markdown separators from metadata blocks.
