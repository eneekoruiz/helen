# Example: High-Converting Landing Page Flow

This example demonstrates using HELEN for building a marketing landing page:

1. **Initialization**:
   ```bash
   helen init-project landing-demo --goal landing
   ```
2. **Strategy & Copy**:
   - `helen prompts show init-creative-direction-and-design-md`
   - `helen prompts show enhance-copy-and-conversion`
3. **Audit Performance & Accessibility**:
   - `helen prompts show apply-basic-accessibility-pass`
   - `helen prompts show apply-basic-performance-pass`
4. **Verification Gate**:
   - `helen check`
