## Correcciones descubiertas durante la implementación

La nueva revisión corrigió aceptación de gates importados sin una observación propia vigente, contradicciones entre pregunta y decisión, finalización con requisitos huérfanos y pérdida de decisiones en briefs de ramas. También corrigió la invalidación de ramas descartadas, la carrera de `creative init`, respuestas MCP excesivas y el éxito JSON incorrecto de un gate fallido. La aceptación de un checkpoint exige tarea, alcance, scripts y estado del repositorio actuales, además de un recibo local. La clave y los archivos pertenecen al mismo usuario: esto impide importar aceptación accidentalmente, no ofrece autenticidad frente a ese mismo usuario.

El importador rechazaba la evolución real del esquema de Codex y podía confundir configuración planificada con identidad verificada. Los campos nuevos conservan su procedencia y la ausencia de identidad nativa excluye los pares. La limpieza Windows de los evaluadores podía ocultar una observación ya obtenida; ahora guarda observaciones y checkpoints antes del borrado, conserva errores de limpieza y finaliza también tras interrupciones. Los límites por intento se registran explícitamente; ampliar el tiempo de una nueva comparación no cambia criterios ni reetiqueta resultados anteriores.

Las skills del repositorio conservan su versión en `metadata.version`, compatible con el validador nativo. Se preservan las copias globales y los snapshots de las evaluaciones anteriores. Los cambios de instrucciones tienen hashes nuevos: los resultados históricos no certifican las instrucciones recién editadas.

El expediente privado `roadmap-2026` conserva el alcance autorizado, las exclusiones y las cuatro respuestas reales sobre proveedores, gasto, Windows y recarga de Codex. Hay un aprendizaje con evidencia sobre la identidad nativa del modelo, un kit creativo inicial editable y un brief preparado para Codex. Los pendientes de observación visual y eficacia general siguen registrados; no se marcan completados por haber creado estos registros.

```powershell
node dist/cli.js work show roadmap-2026

node dist/cli.js knowledge search "evaluation codex model" --paths scripts/run-specialty-evals.mjs

node dist/cli.js outcomes report
npm run prompt:powerpoint
```

Los archivos privados de `.helen` se excluyen del paquete. El `.tgz` entrega comandos, documentación y recursos; los registros reales de este proyecto siguen locales.
