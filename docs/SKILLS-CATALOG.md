# Skills and tools inventory

HELEN distinguishes bundled skills, project installations and a catalog of external resources. Catalog entries are recommendations, not proof of installation.

| Command | What it shows |
| --- | --- |
| `helen skills list` | Bundled HELEN skills |
| `helen skills list --flows` | Bundled skills and generated workflow skills |
| `helen skills installed` | Project installations in `.claude/skills` and `.agents/skills` |
| `helen skills catalog` | External skills, plugins, MCP servers, CLIs, services and references |
| `helen skills catalog --kind skill` | External entries classified as skills |
| `helen skills catalog --category seo` | Entries in one category |
| `helen skills external seo-audit` | Description, source and installation instructions for one entry |
| `helen skills compare taste-skill impeccable` | Compare two catalog entries |

Add `--json` for structured output. From a source checkout, use `node dist/cli.js` instead of `helen` after `npm run build` to inspect that checkout rather than an older globally installed CLI.

`helen skills catalog --check` checks catalog metadata and verification age; it does not verify live upstream URLs or local installation. `helen skills external <id>` prints instructions and does not install anything.

## Global installations

`helen skills installed` does not scan global agent folders or skills supplied by plugins. For this Windows Codex installation, inspect the personal skill directories with:

```powershell
Get-ChildItem -LiteralPath 'C:\Users\User\.codex\skills' -Directory
```

The `.system` directory contains system skills. Plugin skills can be supplied from separate plugin directories, so this folder is not a complete inventory of everything exposed by the running agent. Use that agent's available-skills list and plugin management surface for those sources.

On 2026-10-04, the HELEN catalog contains 41 resources: 15 skills, 5 plugins, 7 CLIs, 5 references, 3 services and 6 MCP servers. This checkout has zero project-local skill installations; the personal Codex folder contains the 12 HELEN skills, alongside system skills.
