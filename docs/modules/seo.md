# SEO Basics (seo)

SEO component + robots.txt + web manifest

## Category
SEO

## Description
Creates a reusable SEO React component, robots.txt, and a basic web manifest for discoverability.

## Problem it Solves
SPAs have poor SEO by default. This provides the foundational elements search engines need.

## Usage Information
- **Risk Level**: low
- **Recommended Skill Level**: beginner

### When to Use
On any public-facing web application.

### When NOT to Use
Internal tools or admin panels not indexed by search engines.
