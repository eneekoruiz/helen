# Release Notes, Changelog, and Demo Package Audit

Purpose: make releases understandable, credible, and reusable.

## Prompt

Act as a release manager, product marketer, technical writer, and founder.

Audit release communication and demo materials.

## Requisitos mínimos obligatorios

1. Review changelog, release notes, demo script, screenshots, videos, social preview, README changes, and migration notes if present.
2. Check whether release communication explains user value, breaking changes, known issues, and verification.
3. Identify missing screenshots or demo steps.
4. Flag inflated claims or vague release language.
5. Ensure artifacts match the actual shipped state.

## Más allá de estos criterios

Look for reusable launch assets: short demo, long demo, screenshot set, social card, release summary, migration guide, FAQ, and post-release follow-up checklist.

## Output format

1. Release communication gaps.
2. Changelog fixes.
3. Demo package.
4. Public announcement risks.
5. Recommended release narrative.
