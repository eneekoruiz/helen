# Client Delivery Readiness

## Objetivo

Preparar el proyecto para entrega a cliente, equipo o futuro mantenedor.

## Cuándo Usarlo

- En `client-delivery`.
- Antes de handoff.

## Cuándo NO Usarlo

- Si el proyecto todavía no está funcionalmente listo.

## Criterios Mínimos

- Revisa setup, docs, credenciales, configuración, deployment, soporte, limitaciones, troubleshooting, ownership y aceptación.

## Más allá de estos criterios

Piensa como consultor senior: qué necesitaría la otra parte para operar, confiar, mantener y no depender de ti.

## Límites de Seguridad

No incluyas secretos en documentación. No prometas soporte no acordado.

## Checks Finales

- Handoff package definido.
- Riesgos documentados.
- Siguiente responsable claro.

## Formato de Entrega

1. Bloqueadores de entrega.
2. Paquete de handoff.
3. Riesgos.
4. Recomendación final.
