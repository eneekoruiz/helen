# Final SEO Audit

## Objetivo

Verificar SEO básico y metadatos antes de publicación.

## Cuándo Usarlo

- En `release-candidate`.
- En proyectos web públicos.
- Antes de compartir landing, docs o portfolio.

## Cuándo NO Usarlo

- Si SEO está explícitamente fuera de alcance.
- Si no hay superficie indexable.

## Criterios Mínimos

- Revisa title, meta description, Open Graph, canonical, robots, sitemap, headings, links, indexability y contenido duplicado.
- Comprueba que los metadatos coincidan con el producto real.

## Más allá de estos criterios

Busca oportunidades de discoverability: páginas comparativas, templates, ejemplos, docs indexables, contenido útil y snippets compartibles.

## Límites de Seguridad

No añadas claims SEO o marketing que el producto no sostenga.

## Checks Finales

- Metadatos básicos presentes si aplican.
- Claims verificables.
- Bloqueadores SEO documentados.

## Formato de Entrega

1. Bloqueadores.
2. Mejoras.
3. Oportunidades.
4. Warnings.
