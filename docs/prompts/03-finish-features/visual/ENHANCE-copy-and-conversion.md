# Copy and Conversion

## Goal

Remove automatic-writing traces from the copy and turn a good-looking interface into one that drives action, without changing what the product really offers and without dark patterns.

## Use when

- Before delivering a landing, portfolio or client site; before paid campaigns or a launch.
- The copy sounds right but interchangeable, or the site is visually strong but does not lead to action.

## Requirements

1. **Humanize:** rewrite AI patterns (staged run-ups, forced triples, inflated importance, empty sales language, symmetric structure) with concrete, verifiable business detail. Helper: `helen skills external humanizer`.
2. **Map conversion:** primary and secondary CTA, objections, friction and trust points per section.
3. **Fix:** main headline and value proposition, CTA text and hierarchy, proof placed close to the action, forms (remove unnecessary fields, clear errors, confirmation), pricing cues, perceived risk. Framework helper: `helen skills external cro-optimization`.
4. **Claims:** each needs real backing; otherwise propose an honest alternative and list it for client confirmation.
5. **Measure:** conversion events, funnel steps, reversible changes and A/B hypotheses when traffic allows.
6. Keep i18n and CMS fields intact: change the text, not the structure.

## Beyond the checklist

Read it aloud: if it could sit on any competitor's site, rewrite it with a detail only this client can say. Every section must move toward conversion, reduce an objection or increase desire, or go.

## Limits

- Never invent testimonials, metrics, logos, awards or guarantees; never hide costs, conditions or limits.
- No dark patterns; flag any legal, privacy or pricing text change.

## Output

```text
Done. / Done with warnings.

Changes applied:
- 1-3 bullets with the exact changes

Manual actions:
- None. / what the user must do (e.g. set a variable, provide real images)
```

Also include the five highest-impact before / after changes and the claims the client must confirm.
