# Conversion-Led Hero

## Goal

Create a first screen that can sell without explaining the whole page, opening the tension "this is for me and I want to see more".

## Use when

- Building the first screen of a landing, portfolio, product or SaaS, or when the current hero is pretty but does not sell.

## Requirements

1. Specific main promise, visual proof, primary and secondary CTA, trust signals and the main objection above the fold.
2. Non-generic composition, a real (or intentionally generated) visual, restrained type hierarchy, human microcopy.
3. A visible hint of the next section.
4. Responsive without overlap, controlled LCP (the hero image or text is the LCP element and loads first), accessibility, motion with a function.

## Limits

- No empty phrases like "Transform your business".
- Do not hide the product, an orientative price or the CTA when people need them; no abstract art when the product needs inspection.

## Output

```text
Done. / Done with warnings.

Changes applied:
- 1-3 bullets with the exact changes

Manual actions:
- None. / what the user must do (e.g. set a variable, provide real images)
```
