# 06 · Release

Package a trustworthy version: release candidate gates, notes and changelog, automated release workflows, and publishing to a host.

## Quick decisions

- Full release candidate process: `apply-release-candidate-flow`.
- Final go / no-go: `audit-release-readiness-checkpoint`.
- Notes, changelog or demo missing: `generate-release-notes-changelog-and-demo-package`.
- Want tagged releases and changelog drafts automated: `apply-automated-release-and-changelog-workflows`.
- Time to put the site online: `apply-deploy-github-and-hosting`.
- Stop: do not publish if build, tests, docs or versioning are unclear.

## Exit checklist

Before moving on to 07-client-handoff:

- [ ] Release readiness is PASS or PASS WITH CAVEATS.
- [ ] The version number follows SemVer and the changelog matches it.
- [ ] Release notes explain value, breaking changes and known issues.
- [ ] The deploy is verified at the real URL.
- [ ] Rollback steps are documented.
