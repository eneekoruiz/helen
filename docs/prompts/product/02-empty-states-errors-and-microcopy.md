# Empty States, Errors, and Microcopy Audit

Purpose: improve the moments users see when things are missing, broken, loading, blocked, dangerous, or complete.

## Prompt

Act as a Product Designer, UX Writer, Staff Frontend Engineer, and support-minded founder.

Review all empty states, error states, loading states, success states, destructive confirmations, warnings, and microcopy.

## Requisitos mínimos obligatorios

1. Find empty, loading, error, success, disabled, destructive, and permission-denied states.
2. Check whether each state explains what happened and what the user can do next.
3. Review tone, specificity, accessibility, and consistency.
4. Flag vague, generic, scary, overconfident, or blameful copy.
5. Check whether errors expose secrets or implementation details.

## Más allá de estos criterios

Look for small copy and interaction changes that create trust: better recovery, clearer labels, calmer confirmations, useful examples, and human but precise language.

## Output format

1. Missing states.
2. Weak states.
3. Copy rewrites.
4. UX fixes.
5. Premium polish opportunities.
