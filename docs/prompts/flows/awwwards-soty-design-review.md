# Awwwards and Site of the Year Design Review Flow

## Objetivo

Revisar una experiencia web con un estándar de diseño visual, interacción y memorabilidad propio de Awwwards/Site of the Year.

## Fase Ideal

Cuando el producto ya funciona y se quiere elevar una web pública, landing, portfolio o showcase.

## Prompts Incluidos

1. `../design/01-general-design-improvement-audit.md`
2. `../design/02-awwwards-soty-visual-excellence-audit.md`
3. `../steps/visual/premium-visual-pass.md`
4. `../steps/visual/responsive-pass.md`
5. `../steps/accessibility/basic-accessibility-pass.md`
6. `../steps/performance/basic-performance-pass.md`

## Checkpoints Entre Pasos

- Después del design audit: decidir si el objetivo es award-level o product-polish.
- Después del visual pass: `../checkpoints/visual-ux-regression-checkpoint.md`
- Final: revisar performance/accessibility warnings antes de recomendar efectos visuales pesados.

## Condiciones para Avanzar

- El flujo principal funciona.
- Los cambios visuales no dañan claridad, accesibilidad ni performance.
- La dirección creativa no contradice el producto.

## Cuándo Detenerse

- La experiencia no tiene base visual suficiente para un pass awards-level.
- Las mejoras requieren nueva dirección creativa.
- El proyecto necesita primero UX básica o contenido real.

## Qué Hacer si Falla Algo

Separar defectos de craft de decisiones creativas. Aplicar solo mejoras acotadas; proponer cambios grandes.

## Resumen Final

1. Veredicto Awwwards/SOTY.
2. Mejoras visuales críticas.
3. Interacción y motion.
4. Riesgos de performance/accessibility.
5. Próxima dirección creativa.
