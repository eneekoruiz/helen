# Project Prompts

This directory contains reusable project prompts organized by lifecycle stage.

The current collection is intentionally small and intentionally deep. It is designed to be used, not admired.

## How This Is Organized

- [final/](final/README.md)
  Deep end-of-project audits and closeout prompts.

## Current Recommendation

If you are closing a project, start in [final/README.md](final/README.md).

That section includes:

- what each prompt is for,
- when to use it,
- the correct order,
- the minimum useful path,
- the full hard-closeout path.

## Important Design Rule

There are no "lite" or ultrashort variants here on purpose.

These prompts are meant for thorough final reviews where losing detail is worse than spending a few more minutes reading. If a prompt feels long, that is usually a sign that the audit surface is broad, not that the prompt should be reduced.
