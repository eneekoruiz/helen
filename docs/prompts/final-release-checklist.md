# Final Release Checklist

Use this checklist at the end of a project before calling it finished.

## Checklist

- The project works locally on a clean setup.
- The main build passes.
- Lint, tests, and type checks pass if the project includes them.
- The README reflects the real project, current commands, and setup.
- DeepWiki is added or intentionally skipped.
- Screenshots are real, current, and worth keeping.
- An OpenGraph or social preview image exists if the project will be shared publicly.
- GitHub description and topics are defined and accurate.
- `.env.example` is present if environment variables are required.
- No secrets, tokens, local paths, or private credentials are committed.
- No false claims remain in the README, docs, or repository metadata.
- The project is clean enough to share in a portfolio, on LinkedIn, or with clients if it genuinely deserves it.
