# 09 · Future knowledge

Make the project survive you: onboarding, ownership, decisions, runbooks, AI context, resilience and upgradeability.

## Quick decisions

- New developer or handoff coming: `audit-developer-onboarding-and-knowledge-gaps`.
- Access or knowledge depends on one person: `audit-bus-factor-and-ownership`.
- AI assistants lack context: `generate-ai-context`.
- A costly decision was just made: `generate-decision-log`.
- Nobody knows how to deploy, roll back or restore: `generate-operations-runbook`.
- Archiving or pausing the project: `apply-knowledge-snapshot`.
- Yearly health: `audit-resilience-and-upgradeability`.

## Exit checklist

Before moving on to the next project cycle:

- [ ] A new developer reaches a green test without private help.
- [ ] No critical account, payment or secret depends on one person.
- [ ] Key decisions have ADRs.
- [ ] A runbook covers deploy, rollback, restore and rotation.
- [ ] An AGENTS.md gives assistants the right context.
