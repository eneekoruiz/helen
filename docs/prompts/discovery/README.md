# Prompts de Discovery

Esta carpeta existe para descubrir lo que una checklist final no sabe preguntar.

Usala cuando quieras someter metodologia, estructura de carpetas, arquitectura, producto, UX, operacion, seguridad, calidad y presentacion a una revision profunda.

## Prompts

1. [01-methodology-and-blind-spots-audit.md](01-methodology-and-blind-spots-audit.md)
   Revisa la metodologia completa, categorias faltantes, estructura de prompts y puntos ciegos.

2. [02-product-ux-and-premium-quality-audit.md](02-product-ux-and-premium-quality-audit.md)
   Evalua producto, UX, UI, copy, friccion, coherencia y sensacion premium.

3. [03-architecture-operations-and-risk-audit.md](03-architecture-operations-and-risk-audit.md)
   Revisa arquitectura, seguridad, SRE, DevOps, QA, mantenibilidad y riesgos futuros.

## Como Usarlos

Ejecutalos antes de los prompts finales si el proyecto es importante, publico, comercial, reutilizable o parte de un portfolio.

La salida esperada no es solo una lista de defectos. Debe incluir:

- categorias faltantes;
- riesgos no obvios;
- oportunidades de alto apalancamiento;
- cambios pequenos con mucho impacto;
- decisiones que conviene tomar explicitamente;
- cosas que parecen correctas pero no estan suficientemente probadas.
