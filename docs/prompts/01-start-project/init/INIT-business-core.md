# Business Core

## Goal

Turn a blank canvas into an operational brief: what is sold, to whom, why they should believe it, and which action the site must drive. Everything else (design, scaffold, copy) is built on this.

## Use when

- Starting a project from zero, in an editor agent or an AI builder (Lovable, Bolt, v0, Cursor...).
- Niche, audience, offer, references or differentiation are still unclear.

## Requirements

Ask for any missing input before writing: niche, main offer, target audience, main pain, desired outcome, price or deal value, competitors or references, brand tone, technical constraints.

1. A clear, concrete, sellable **positioning hypothesis**.
2. The offer as a high-value narrative: problem, tension, own mechanism, proof, action.
3. **Conversion hierarchy:** primary CTA, secondary CTA, critical objections and trust signals.
4. **Copy rules:** human, specific, professional; explicitly ban AI-sounding copy (inflated phrases, empty claims, clichés, generic enthusiasm, adjectives without proof).
5. Expected visual quality and interaction tone (restrained transitions, precise hover states, form feedback, purposeful motion), without trading away commercial clarity.
6. A prioritized list of sections, each with its job in the conversion path.

## Beyond the checklist

If a more profitable way to structure the offer exists, propose it. Prioritize conversion, trust and differentiation over surface aesthetics.

## Limits

- Never invent metrics, logos, clients, awards or testimonials.
- Leave concrete, actionable placeholders where critical data is missing.
- Stop if offer, audience and conversion goal are all unknown: ask instead.

## Output

An operational brief with: positioning, audience and objections, conversion architecture, tone and copy rules, expected visual system, interaction requirements, prioritized sections, open questions. Next: `init-creative-direction-and-design-md` and `init-architecture-and-scaffold`.
