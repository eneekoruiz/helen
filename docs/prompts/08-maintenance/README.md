# 08 · Maintenance

Keep the project, its dependencies, its data and its public presence healthy over time, and keep HELEN itself sharp.

## Quick decisions

- About to install a skill, plugin, CLI or MCP server: `audit-third-party-tools-and-mcp` first.
- Dependencies drifting: `apply-dependabot-and-auto-maintenance`.
- Backups, exports or migrations unclear: `audit-data-lifecycle-and-portability`.
- Repository rules and licenses: `audit-repository-governance-and-compliance`.
- Growth stalled or no metrics: `audit-growth-and-metrics`.
- Several audits to merge into one plan: `audit-cross-audit-synthesis`.
- Yearly check of your professional presence: `audit-yearly-professional-presence-review`.
- Changed HELEN prompts or skills: `apply-prompt-library-maintenance-flow`.

## Exit checklist

Before moving on to 09-future-knowledge:

- [ ] Dependencies update automatically with CI protection.
- [ ] Backups were restored at least once.
- [ ] Third-party tools installed were reviewed and are listed.
- [ ] Branch protection and security features are on.
- [ ] Metrics that drive decisions exist and respect privacy.
