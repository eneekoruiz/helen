# HELEN GitHub Template Repository

This repository is designed to be used directly as a GitHub Template Repository ("Use this template").

## Included Out-of-the-Box
1. **Pre-configured Git Hooks**: `.githooks/` for pre-commit, pre-push, and Conventional Commits `commit-msg`.
2. **Dependabot Configuration**: Automatic patch updates with security monitoring.
3. **CI Workflows**: GitHub Actions test matrix across operating systems, plus CodeQL security scanning.
4. **Agent Guidance**: Pre-populated `AGENTS.md`, `CLAUDE.md`, `.cursor/rules/`, and `.agents/rules/` for Antigravity and Codex.
5. **Complete Skill Library**: 17 domain skills ready for zero-latency invocation.
