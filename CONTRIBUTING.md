# Contributing to HELEN

Thank you for considering contributing. This project values stability, clear tests, and small, well-reviewed changes.

Quick guide:

1. Fork the repo and create a topic branch.
2. Run `npm ci` and `npm run build` locally.
3. Add tests for new behavior and ensure `npm run test` passes.
4. Keep changes focused and avoid large refactors without prior discussion.
5. Open a PR with a clear description and link to any related issue.

Code style: run `npm run format` before committing.
